# Claim boundaries — emergent service-intent protocols

Optional **distributed-intelligence research extension**. Not a fourth dissertation paper.

GENOME is a **public University of Oulu / CWC job-theme** (emergent communication protocols in beyond 5G/6G). This repo is aligned to that public theme. It is **not** evidence of an appointment, studentship, or funded post.

## Allowed vs forbidden claims

| Claim | Allowed today only if |
|---|---|
| Agents exchange messages | CPU env/channel tests PASS |
| Communication efficiency (bits, silence, bits/success) | Seeded synthetic rollouts + JSON |
| Entropy / MI / topographic similarity | Labeled **estimates**; CPU reproducible |
| Intervention effect (silence/random/adversarial) | Causal tests PASS; no presence bonus |
| Structured signaling candidate | Entropy + MI + topo-sim + intervention + ≥3 seeds **and** `emergent_language_claimed: false` |
| Emergent language | **Never** from message exchange alone; this repo does not authorize the phrase as a result |
| GPU acceleration | CUDA device + measured JSON; else `BLOCKED_GPU` |
| Oulu affiliation | **Never** |

## Evidence class

Default host evidence is `SYNTHETIC_SIM`. Smoke ≠ scientific final.

Baselines: `no_comm`, `fixed_protocol`, random, PPO discrete-message entropy, IPPO/MAPPO, VDN/QMIX, DIAL, TarMAC — only cells that exist in `results/*/STATUS.json` may be cited.
